# 星星电台周月执行进度看板契约

## 输入 JSON

```json
{
  "month": "202610",
  "checkpoint": { "mode": "auto" },
  "tasks": [
    {
      "name": "卫龙舂鸡脚",
      "brand": "卫龙",
      "product": "舂鸡脚",
      "pm": "",
      "task_id": "",
      "monthly_targets": {
        "samples": null,
        "scripts": null,
        "publishes": null,
        "amount": null
      },
      "weekly_plans": [],
      "actuals": [],
      "feedback": []
    }
  ],
  "output": "/absolute/path/output.xlsx"
}
```

- `month`：必填，格式 `YYYYMM`。
- `checkpoint`：默认使用 `{"mode":"auto"}`，由日期和已填写实际字段识别检查点。只有用户明确要求手动控制时才使用 `{"mode":"manual","week":3,"stage":"mid"}`；`week` 为 1 至当月自然周数，`stage` 可用 `mid`、`tail`、`full` 或周中、周尾、整周。
- `tasks`：至少 1 项。`name` 是不带年月前缀的产品名称，直接用于生成单任务工作表名，并且在任务清单内应保持唯一；`brand`、`product`、`pm`、`task_id` 可为空。
- `monthly_targets`：四项可编辑月目标。键固定为 `samples`、`scripts`、`publishes`、`amount`。
- `weekly_plans`：按自然周顺序排列，每项使用同样的四个指标键。未提供的周保留空白，不自动平摊月目标。
- `actuals`：按周排列；每周可包含 `mid`、`tail`、`full`，其内部仍使用四项指标键。数值为本周累计值。
- `feedback`：按周排列；每周可包含 `mid`、`tail`、`full` 三段文本。
- `output`：必填绝对路径，也可用命令行 `--output` 覆盖。

所有指标只接受非负数或空值。输入 `0` 是有效数据；`null`、缺键或空字符串表示待填写。单任务工作表名不添加月份；名称最长 31 个字符，非法字符会替换。输入名称应保持唯一，若仍发生重名，脚本会追加序号以防止覆盖。

## 自然周拆分

从每月 1 日开始，以周一至周日为一周；首周和末周允许不足 7 天。标题示例：`第一周（1001-1004）周四-周日`。月份可能产生 5 个或 6 个周区块，所有公式和汇总列必须随周数扩展。

## 汇总页

表名为 `${YYYYMM}汇总`。

### A:J 固定列

| 列 | 内容 |
| --- | --- |
| A | 品牌 |
| B | 产品 |
| C | 组长/PM |
| D | 规划发布数 |
| E | 完成发布数 |
| F | 发布完成率 |
| G | 规划发布金额 |
| H | 完成发布金额 |
| I | 金额完成率 |
| J | 进度状态 |

每个任务只占 1 行。A:H 通过公式链接任务页的 `A3`、`B3`、`B1`、`E5`、`F5`、`G5`、`E6`、`F6`。I 列用完成发布金额除以规划发布金额；J 列按统一阶段检查点分别计算发布数、发布金额，并显示较弱结果、百分比和弱项。F、I 两列均使用蓝色数据条并保留百分比文字。

### 每周 6 列

从 K 列开始，每周依次为：规划发布数、完成发布数、发布完成率、规划发布金额、完成发布金额、金额完成率。

周完成数和周完成金额通常取最新已填写阶段值：整周优先，其次周尾，再次周中；三者均为空时保持空白。当前检查周必须取自动识别阶段的对应字段，不能用更早阶段回退；对应字段未填时保持空白并使该任务状态显示“待填写”。通过 `COUNT` 识别已填写的真实 0，避免把 0 当成空白。周计划为 0 时完成率显示 `n.a.`，计划大于 0 且实际为 0 时显示 `0%`。

每周的发布完成率和金额完成率均使用蓝色数据条，同时保留百分比数值。每周规划/完成金额与月度规划/完成金额统一使用人民币千分位格式 `"¥"#,##0`，不显示小数。

任务行下方保留 1 行合计。合计行只汇总数值，不把空白伪装成真实零；完成率由合计实际除以合计目标计算。合计行下方显示“自动检查周”“自动阶段”“当前应达比例”；自动模式下三项均由公式计算，手动模式下周次与阶段才可编辑。

## 任务明细页

工作表名直接使用任务的 `name`，不添加 `${YYYYMM}-` 或其他日期前缀；必要时安全截断并保证唯一。汇总页所有跨表公式必须引用最终生成的任务页名称，并统一使用 `INDIRECT("'产品名称'!单元格")` 保留和转义完整页名。这样既支持空格、括号、单引号等字符，也避免纯中文页名在导出或兼容重算时被误判为名称。

当前 Artifact Tool 重新导入时不能计算 `INDIRECT`。脚本导出的工作簿必须在 LibreOffice 或目标 Excel 中完成全量重算并另存后才可交付；最终验证以重算后的缓存值、公式文本和公式错误扫描为准。

### A:H 固定区

| 列 | 内容 |
| --- | --- |
| A | 品牌 |
| B | 产品 |
| C | 星图任务 ID |
| D | 数据维度 |
| E | 月度规划 |
| F | 月度完成 |
| G | 月度完成率 |
| H | 进度判断 |

第 3 至 6 行固定为：寄样数、脚本数、发布数、落地金额。

- F 列：每个周区块取最新已填写阶段值，再对各周求和；所有阶段均未填写时保持空白。
- G 列：月目标为空时保持空白；月目标为 0 时显示 `n.a.`；月目标大于 0 且月完成为 0 时必须显示 `0%`。
- H 列：分别按四项指标和汇总页统一阶段检查点判断执行进度，并显示阶段达成率。
- 第 7 行：校验四项月目标是否分别等于所有周计划之和；目标未齐时显示“待填写”，不一致时显示“请检查月度规划与周计划”。

### 每周 7 列

每周依次为：单周规划、周中完成、周中进度、周尾完成、周尾进度、整周实际、整周进度。

周中进度、周尾进度、整周进度均使用蓝色数据条并显示百分比数值。落地金额行的月度规划、月度完成、每周计划、周中完成、周尾完成和整周实际均使用人民币千分位格式 `"¥"#,##0`，不显示小数。

第 7 行在周计划列留空，并将后续 6 列拆成三个独立的合并填写区：周中反馈、周尾反馈、整周反馈。默认提示要求填写进度、差距、动作、负责人、完成时间和验证数字。

## 公式口径

进度判断引用汇总页统一自动检查点。自动检查点先用 `TODAY()` 限定最大可用自然周，再从该周向前寻找有实际数据的最新周；同周依次检查整周、周尾、周中字段。数值 0 视为已填写，未来周数据在自然日期到达前不参与识别。阶段应达计划为：已结束周按 100% 计入，当前检查周按周中 50%、周尾 85%、整周 100% 计入，未来周不计入。阶段完成率为：

```excel
阶段累计实际 / 阶段应达计划
```

阶段完成率低于 95% 为“滞后”，95% 至 105%（含边界）为“正常”，高于 105% 为“超预期”。状态显示整数百分比；汇总页对发布数和发布金额取较弱结果并标注弱项。检查范围内规划未填显示“计划待补”，实际未填显示“待填写”，规划为 0 且实际为 0 显示“无计划”，规划为 0 且实际大于 0 显示“计划外完成”。

## 样式与条件格式

- 深蓝表头、白字；工作表网格线关闭。
- 浅黄色表示需要填写的目标和计划；浅蓝色表示累计实际；三段反馈区保持独立且可直接输入。
- 月度完成率和所有单周完成率使用蓝色数据条并显示数值；空白和 `n.a.` 不显示数据条。
- 所有金额单元格使用人民币千分位格式 `"¥"#,##0`，不显示小数点。
- 周中进度小于 50%、周尾进度小于 85%、整周进度小于 100% 时使用红色粗体文字；空白和 `n.a.` 不触发。
- “滞后”使用浅红提示，“正常”使用浅绿提示，“超预期”使用浅蓝提示，“计划待补”和“待填写”使用浅黄提示；“无计划”使用灰色，“计划外完成”使用浅蓝提示。
- 冻结任务页前 2 行和前 8 列；冻结汇总页前 2 行和前 10 列。

## 验收清单

1. 核对月份、任务数、工作表数量、工作表名和自然周数量；所有任务页仅使用产品名称且不含年月前缀。
2. 抽查首个、中间、最后任务：汇总 A:H 及各周区块的 `INDIRECT` 跨表引用均指向其对应任务页；I 列金额完成率和 J 列进度状态公式正确，纯中文名与含括号等字符的名称都能正确重算。
3. 抽查 0 与空白：填入 0 后应显示 0%，全部留空时仍为空白或“待填写”。
4. 抽查周内累计：周中、周尾、整周填入不同累计值，周实际应取最新已填写阶段值；累计下降时不得回取较高旧值。
5. 抽查阈值边界：50%、85%、100% 不标红；49.9%、84.9%、99.9% 标红。
6. 检查阶段判断边界：阶段累计实际为阶段应达计划的 95% 和 105% 时均为“正常”，94.9% 为“滞后”，105.1% 为“超预期”；未来周不计入当前状态。
7. 检查月目标与周计划校验公式。
8. 检查汇总页月度及每周的发布/金额完成率、任务页每周周中/周尾/整周进度均存在蓝色数据条，且原有红字阈值仍生效。
9. 检查汇总页和任务页全部金额单元格均为人民币千分位、无小数格式，数值类型未被转成文本。
10. 扫描公式错误并渲染所有工作表，确认没有截断、重叠或不可编辑的输入区。
11. 在 LibreOffice 或目标 Excel 中重算副本并复查跨表结果；当前周只填周中时应识别为周中，新增任一周尾有效数字（包括0）后应识别为周尾，未来周误填不得提前跳周。对应比例应为50%、85%、100%，状态同步更新。
